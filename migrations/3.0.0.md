# Kartograph 3.0.0 — conversation, intent and mapping in kartograph/

## Target state

- `kartograph/` at the project root is one flat Open Knowledge Format bundle: `index.md`
  (frontmatter `okf_version: "0.2"` and `kartograph_version: 3.0.0`), `log.md`, and
  documents named `<YYYY-MM-DD-HHMM>-<slug>.<type>.md` whose `type` is Conversation,
  Intent or Mapping. No subdirectories. Whatever an earlier `kartograph/` held beside
  that (`decisions/`, `surveys/`, other files) lives in `docs/kartograph-v0/`.
- There is no `intents/` directory. Every earlier intent is
  `kartograph/<stamp>-<slug>.intent.md` with `type: Intent`, a one-sentence
  `description`, its old status, and `legacy-no-conversation` first in `sources`.
- Provenance points into `kartograph/`: `# Source intent: kartograph/<file>.intent.md` in
  `.feature` files (header and per scenario), ``- Intent: `kartograph/<file>.intent.md` ``
  and every other ``- <Words> intent: `…` `` line in `capability.md`, and
  `../kartograph/<file>.intent.md` in `knowledge/` concepts and `knowledge/log.md`.

## Recognise

A `kartograph/index.md` without `kartograph_version`, or no `kartograph/index.md` while
the project holds Kartograph files from before: stamp-named files in `intents/`, a
`capability.md` or a `# Source intent:` line under `features/`, a `knowledge/index.md`
with `okf_version`, or a `.kartograph/` directory. A directory name alone is no evidence:
a project with none of these is new.

## Do

- Mechanical, `scripts/migrate-kartograph.js`: move every entry of an earlier
  `kartograph/` that is not a flat document to `docs/kartograph-v0/` (never overwriting;
  a clash stays and is reported), move and convert every intent, rewrite the provenance
  lines (never a step, scenario or title), write `index.md` and `log.md`, remove the empty
  `intents/`.
- Judgment: an old `related` entry that names no intent file cannot be converted; the
  intent validator reports it. Move its text to the intent's `## Notes` and drop it from
  `related`. No mapping is written for a legacy intent.
- Validation errors that existed before the migration (a knowledge bundle in an older
  layout, a section missing from an intent's body) are not fixed by inventing content:
  each is noted under the migration line in `kartograph/log.md` and reported.
